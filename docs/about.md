# 关于本项目



## 项目简介



本项目是开源软件课程的个人实践项目，使用 Markdown 编写文档，通过 MkDocs Material 生成静态网站，并使用 GitHub Actions 自动部署到 GitHub Pages。

我希望把这个网站作为整理课程笔记和项目文档的起点，在学习编程的同时，逐步养成记录操作步骤和解决问题过程的习惯。



## 项目目标



- 编写首页、关于本项目、使用指南和 API 参考四个页面。

- 理解文档源码、构建产物和公开网站之间的关系。

- 实现推送文档后自动构建、自动部署和网页更新。

- 通过提交记录、运行日志和实际截图记录实践过程。



## 技术组成

| 工具 | 在本项目中的作用 |
| --- | --- |
| Markdown | 编写页面的标题、正文、列表、表格和代码示例 |
| MkDocs Material | 将 Markdown 文档构建成带有主题和导航的静态网站 |
| Git | 在本地记录修改，并与 GitHub 仓库同步提交 |
| GitHub | 保存项目源码、配置文件和实验报告 |
| GitHub Actions | 自动执行依赖安装、网站构建和部署任务 |
| GitHub Pages | 托管构建完成的网站，提供公开访问地址 |

## 从文档到网站



我在电脑上修改 docs 目录中的 Markdown 文件，记录提交后推送到 GitHub。

符合触发条件的推送会启动 GitHub Actions。工作流使用 MkDocs 构建网站，将生成的 site/ 目录上传为构建产物，再部署到 GitHub Pages。

部署完成后，访问者就可以通过网站地址查看更新后的文档。
